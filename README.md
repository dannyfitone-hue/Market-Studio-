# Market Studio website

Complete static website with the approved Market Studio logo and interactive eight-step ad production walkthrough.

## Upload to GitHub

Unzip this archive, then upload the extracted files and the assets folder to the root of your repository. Keep index.html at the top level. Upload the extracted website files rather than only the ZIP.

## Preview

Open index.html in a browser. This website uses plain HTML, CSS, and JavaScript. No dependency installation or build step is required.

## Files

- index.html: website copy and all eight process steps.
- style.css: main layout and responsive logo placement.
- process.css: 3D walkthrough design and animations.
- script.js: shared behavior and motion controls.
- process.js: step selection, tour playback, responsive 3D sizing, and color comparison.
- responsive.css: phone/tablet layouts, readable text, and large touch controls.
- responsive.js: compact navigation and the swipeable ad gallery.
- assets/: product images, client logos, and transparent Market Studio logo assets.
- ASSET_SOURCES.md: image and logo provenance.
- .nojekyll: static hosting marker.

## Branding

The header and footer use market-studio-logo.png, the black logo on a transparent background. market-studio-mark.png is the matching icon. Both sit directly on the page without a colored box or presentation background.
